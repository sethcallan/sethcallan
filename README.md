## About Me

I'm Seth Callan. My background is in high-level analytics and systems work — the kind of problem-solving where you break down complex behavior, identify bottlenecks, and build tools that make things more efficient.

I'm now applying that same approach to cloud engineering. I'm focused on AWS, infrastructure, and automation, and I'm building projects that mirror real production environments: VPC design, serverless applications, Terraform deployments, CI/CD pipelines, event-driven systems, and containerized workloads.

Everything on this GitHub is hands-on. No copied tutorials, no filler, no half-finished coursework. If it's here, I built it to understand how it works and how it behaves under real-world conditions.

My goal is to become a strong Cloud Engineer on the path toward Cloud Architecture. This GitHub is the record of that progression — clear, structured, and continually improving.
